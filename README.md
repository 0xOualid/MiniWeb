## Running the Projects

Most projects can be run directly in a web browser.

### 1. Clone the repository

```bash
git clone https://github.com/0xolid/MiniWeb.git
```

### 2. Enter the repository

```bash
cd MiniWeb
```

### 3. Open a project

For example:

```text
Projects/01-Easy/Hello/index.html
```

Open `index.html` in your web browser.

You can also use a development extension such as **Live Server** in Visual Studio Code for a better development experience.
